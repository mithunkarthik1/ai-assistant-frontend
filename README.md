# ai-assistant-frontend

A modern, responsive React + Vite chat interface for the WorkPilot AI Assistant Platform.

## Features

- **Real-time AI Chat**: Connects to the RAG cognitive backend.
- **Interactive Policy Handbook Modal**: In-app policy browser.
- **Session Management**: Chat history tracking and context memory.
- **Responsive UI**: Clean design with Lucide icons and sleek modern components.

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
```bash
npm install
```

### Environment Variables
Copy `.env.example` to `.env`:
```bash
VITE_API_BASE_URL=http://localhost:8000
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
